# 큐블록 8비트 픽셀 에셋 가이드

기준 화면은 1280×720입니다. 모든 이미지는 픽셀 1칸을 4px로 키운 PNG이고 배경은 투명합니다. 게임에서는 **원본 크기 그대로(1:1)** 그려야 선명합니다.
`screens/` 폴더의 합성 예시(플레이, 일시정지, 게임오버, 클리어, 스테이지 선택)는 이 폴더의 PNG만으로 만든 것입니다. 아래 좌표를 그대로 쓰면 예시와 똑같이 배치됩니다.

> 좌표는 모두 **화면 왼쪽 위 기준, 이미지 왼쪽 위 모서리**(px)입니다. pico2d로 옮기는 방법은 맨 아래에 있습니다.

### 보드 칸
칸 (행 r, 열 c)의 왼쪽 위 = **(694 + 64·c, 104 + 64·r)** (r=0이 맨 위 줄)
블록, 방해 블록, `ghost`는 모두 64×64이고 이 위치에 그대로 그립니다.

### 큐브 (큐브 이미지 위치 = (CX, CY) = (48, 104))
- 몸체: `cube_body.png`를 (CX, CY)에 그립니다.
- **앞면** 스티커 (행 r, 열 c): `sticker_front_*.png` (64×64) → **(CX + 16 + 64·c, CY + 120 + 64·r)**
- **윗면** 스티커 (열 c, 깊이 k): `sticker_top_*.png` (92×32) → **(CX + 20 + 64·c + 32·k, CY + 80 − 32·k)**
  - k=0이 앞면 바로 위 줄, k=2가 가장 뒤 줄입니다.
- **옆면(오른쪽)** 스티커 (행 r, 깊이 k): `sticker_side_*.png` (32×92) → **(CX + 216 + 32·k, CY + 88 + 64·r − 32·k)**
  - k=0이 앞면 바로 옆 줄입니다.
- 앞면 강조: `front_frame_0/1.png` (336×336)를 (CX, CY)에 겹칩니다. 두 장을 번갈아 그리면 깜빡입니다.
- 지정 색 표시: `front_mark_0/1.png` (64×64)를 지정 색인 앞면 칸 위에 겹칩니다.
- 줄 선택: `select_row_0/1.png` (208×80) → (CX + 8, CY + 112 + 64·r)
- 칸 선택: `select_col_0/1.png` (80×208) → (CX + 8 + 64·c, CY + 112)
- 줄 화살표: `arrow_left.png` 등 (40×40) → 행 r 왼쪽 (CX − 32, CY + 132 + 64·r), 열 c 아래 (CX + 28 + 64·c, CY + 320)

### 이번/다음 색 패널 (패널 위치 = (400, 104))
- 이번 색: `cube/sticker_front_*.png` → (432, 192)
- 다음 색: `hud/mini_*.png` (48×48) → (552, 204)

### 블록 미리보기 (패널 위치 = (400, 296))
- 3×3 칸 (행 r, 열 c): `hud/mini_*.png` (48×48) → (448 + 48·c, 376 + 48·r)
- 블록이 3칸 미만이면 `mini_gray.png`를 씁니다.

### 에너지 게이지 (게이지 위치 = (16, 16))
- 칸 i (0~29): **(80 + 16·i, 32)**에 `energy_seg_full.png` (12×32)를 그립니다.
- 에너지가 적을 때는 `energy_seg_low.png`(빨강)를 쓰고, `energy_seg_blink.png`(흰색)와 번갈아 그리면 깜빡입니다.

### 숫자
`hud/digits_white.png`, `digits_yellow.png` (468×40): 한 글자가 36×40이고 순서는 `0123456789+x/`입니다.
- 글자 i의 잘라낼 위치: x = 36·i
- 점수 숫자: (784, 16)부터 36px 간격으로 씁니다 (6자리).
- 턴 숫자: (1100, 16)부터 씁니다.
- 노란 숫자는 `+90` 같은 점수 팝업에 씁니다.

## pico2d로 옮기기

pico2d는 원점이 **왼쪽 아래**이고 `draw(x, y)`의 x, y가 **이미지 중심**입니다. 위 표의 왼쪽 위 좌표 (L, T)와 이미지 크기 (w, h)를 이렇게 바꿉니다.

```python
H = 720

def draw_tl(img, L, T):
    """왼쪽 위 좌표(L, T)에 이미지를 그린다."""
    img.draw(L + img.w / 2, H - T - img.h / 2)

def draw_frame(sheet, i, fw, fh, L, T):
    """가로 시트의 i번째 프레임을 왼쪽 위 (L, T)에 그린다."""
    sheet.clip_draw(i * fw, 0, fw, fh, L + fw / 2, H - T - fh / 2)

def draw_number(digits, text, L, T):
    """digits_white.png로 숫자 문자열을 그린다."""
    for n, ch in enumerate(text):
        k = '0123456789+x/'.index(ch)
        digits.clip_draw(k * 36, 0, 36, 40, L + n * 36 + 18, H - T - 20)
```

마우스 좌표는 위쪽 기준이라 `y = H - 1 - event.y`로 뒤집은 뒤 위 표의 영역과 비교하면 됩니다.
