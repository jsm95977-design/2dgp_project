# 큐블록 8비트 픽셀 에셋 가이드

기준 화면은 1280×720입니다. 모든 이미지는 픽셀 1칸을 4px로 키운 PNG이고 배경은 투명합니다. 게임에서는 **원본 크기 그대로(1:1)** 그려야 선명합니다.
`screens/` 폴더의 합성 예시(플레이, 일시정지, 게임오버, 클리어, 스테이지 선택)는 이 폴더의 PNG만으로 만든 것입니다. 아래 좌표를 그대로 쓰면 예시와 똑같이 배치됩니다.

> 좌표는 모두 **화면 왼쪽 위 기준, 이미지 왼쪽 위 모서리**(px)입니다. pico2d로 옮기는 방법은 맨 아래에 있습니다.

### 보드 칸
칸 (행 r, 열 c)의 왼쪽 위 = **(694 + 64·c, 104 + 64·r)** (r=0이 맨 위 줄)
블록, 방해 블록, `ghost`는 모두 64×64이고 이 위치에 그대로 그립니다.

### 큐브 (큐브 이미지 위치 = (CX, CY) = (48, 104))
- 몸체: `cube_body.png`를 (CX, CY)에 그립니다.
- **앞면** 스티커 (행 r, 열 c): `sticker_front_*.png` (64×64) → **(CX + 16 + 64·c, CY + 120 + 64·r)**
- **윗면** 스티커 (열 c, 깊이 k): `sticker_top_*.png` (92×32) → **(CX + 20 + 64·c + 32·k, CY + 80 − 32·k)**
  - k=0이 앞면 바로 위 줄, k=2가 가장 뒤 줄입니다.
- **옆면(오른쪽)** 스티커 (행 r, 깊이 k): `sticker_side_*.png` (32×92) → **(CX + 216 + 32·k, CY + 88 + 64·r − 32·k)**
  - k=0이 앞면 바로 옆 줄입니다.
- 앞면 강조: `front_frame_0/1.png` (336×336)를 (CX, CY)에 겹칩니다. 두 장을 번갈아 그리면 깜빡입니다.
- 지정 색 표시: `front_mark_0/1.png` (64×64)를 지정 색인 앞면 칸 위에 겹칩니다.
- 줄 선택: `select_row_0/1.png` (208×80) → (CX + 8, CY + 112 + 64·r)
- 칸 선택: `select_col_0/1.png` (80×208) → (CX + 8 + 64·c, CY + 112)
- 줄 화살표: `arrow_left.png` 등 (40×40) → 행 r 왼쪽 (CX − 32, CY + 132 + 64·r), 열 c 아래 (CX + 28 + 64·c, CY + 320)

### 이번/다음 색 패널 (패널 위치 = (400, 104))
- 이번 색: `cube/sticker_front_*.png` → (432, 192)
- 다음 색: `hud/mini_*.png` (48×48) → (552, 204)

### 블록 미리보기 (패널 위치 = (400, 296))
- 3×3 칸 (행 r, 열 c): `hud/mini_*.png` (48×48) → (448 + 48·c, 376 + 48·r)
- 블록이 3칸 미만이면 `mini_gray.png`를 씁니다.

### 에너지 게이지 (게이지 위치 = (16, 16))
- 칸 i (0~29): **(80 + 16·i, 32)**에 `energy_seg_full.png` (12×32)를 그립니다.
- 에너지가 적을 때는 `energy_seg_low.png`(빨강)를 쓰고, `energy_seg_blink.png`(흰색)와 번갈아 그리면 깜빡입니다.

### 숫자
`hud/digits_white.png`, `digits_yellow.png` (468×40): 한 글자가 36×40이고 순서는 `0123456789+x/`입니다.
- 글자 i의 잘라낼 위치: x = 36·i
- 점수 숫자: (784, 16)부터 36px 간격으로 씁니다 (6자리).
- 턴 숫자: (1100, 16)부터 씁니다.
- 노란 숫자는 `+90` 같은 점수 팝업에 씁니다.

## pico2d로 옮기기

pico2d는 원점이 **왼쪽 아래**이고 `draw(x, y)`의 x, y가 **이미지 중심**입니다. 위 표의 왼쪽 위 좌표 (L, T)와 이미지 크기 (w, h)를 이렇게 바꿉니다.

```python
H = 720

def draw_tl(img, L, T):
    """왼쪽 위 좌표(L, T)에 이미지를 그린다."""
    img.draw(L + img.w / 2, H - T - img.h / 2)

def draw_frame(sheet, i, fw, fh, L, T):
    """가로 시트의 i번째 프레임을 왼쪽 위 (L, T)에 그린다."""
    sheet.clip_draw(i * fw, 0, fw, fh, L + fw / 2, H - T - fh / 2)

def draw_number(digits, text, L, T):
    """digits_white.png로 숫자 문자열을 그린다."""
    for n, ch in enumerate(text):
        k = '0123456789+x/'.index(ch)
        digits.clip_draw(k * 36, 0, 36, 40, L + n * 36 + 18, H - T - 20)
```

마우스 좌표는 위쪽 기준이라 `y = H - 1 - event.y`로 뒤집은 뒤 위 표의 영역과 비교하면 됩니다.

## 스테이지 특수 블록 (`special/`)

보드 블록과 같은 64×64 크기라서 보드 칸 위치 **(694 + 64·c, 104 + 64·r)**에 그대로 그리면 됩니다. 애니메이션 파일은 프레임이 가로로 이어진 시트입니다.

### 규칙 (확정안)

| 블록 | 규칙 |
|---|---|
| 폭탄 | 숫자가 남은 턴. 0이 되면 터지며 주변 3×3을 지움 (세부 규칙은 미정) |
| 강철 | 줄이 지워져도 사라지지 않음 |
| 해 | 주변 8칸이 모두 차면 활성화됨 (보드 바깥 벽은 찬 칸으로 인정). 활성화되는 즉시 획득하고 주변 3×3이 함께 사라짐. 판정은 **블록 배치 → 해 확인 → 줄 삭제** 순서 |
| 달 | 달이 들어 있는 줄이 지워질 때마다 한 단계 차오름 (초승달 → 반달 → 보름달). 보름달이 된 뒤 한 번 더 지워지면 획득. 그전까지는 줄이 지워져도 남음 |

- 애니메이션 속도: 폭탄 도화선과 이펙트는 초당 8~12프레임, 해·달·강철 반짝임은 초당 4~6프레임이 자연스럽습니다.
- `special_blocks.png`는 전체 모음, `special_blocks.gif`는 해가 뜨고, 달이 차올라 획득되고, 폭탄이 터지는 장면을 보드 위에서 보여 주는 미리보기입니다.

```python
def moon_stage_up(board, r, c):
    """줄 삭제 때 달 칸에서 호출. True면 획득."""
    cell = board[r][c]
    if cell.stage < 3:
        cell.stage += 1          # 차오름 (fx_moon_up 재생)
        return False
    board[r][c] = None           # 보름달 상태에서 한 번 더 지워짐 → 획득 (fx_moon_collect)
    return True
```

## 스테이지 모드: 오프닝 컷신 → 지역 선택 → 스테이지 선택

흐름: 타이틀에서 **스테이지 모드** → (처음 한 번만) **오프닝 컷신** → **지역 선택** → 그 지역의 **스테이지 선택** → 플레이.
오프닝을 이미 봤는지는 최고 기록처럼 파일에 저장해 두고, 두 번째부터는 바로 지역 선택으로 갑니다.
대사와 지역 정보는 `story_data.py`에 모두 들어 있습니다 (pico2d를 쓰지 않는 데이터 파일).

### 스토리 요약
큐브마을 한가운데의 '마을 큐브'는 한쪽 귀퉁이(앞·위·오른쪽이 만나는 코너)가 비어 있습니다. 회색 블록 비에 마을 큐브가 산산조각 나 조각이 지구와 우주로 흩어지고, 마을은 회색으로 물듭니다. 큐비가 조각을 찾아 떠납니다.
비어 있는 코너의 색(노랑·빨강·파랑)은 큐비의 색과 같습니다. 엔딩에서 큐비가 그 자리에 들어가며 마을에 색이 돌아오는 복선입니다.

### 오프닝 컷신 (`story/`)

| 요소 | 파일 | 위치 | 크기 |
|---|---|---|---|
| 장면 그림 | `scene_1.png` ~ `scene_5.png` | (0, 0) | 1280×720 |
| 대사 상자 | `dialog_box.png` | (32, 520) | 1216×184 |
| 이름표 (큐비가 말할 때만) | `name_kubi.png` | (64, 460) | 144×84 |
| 대사 글자 | Galmuri11.ttf, **크기 36**, 흰색 | 첫 줄 (84, 560), 둘째 줄 (84, 612) | 한 줄 25자 안팎, 최대 2줄 |
| 다음 화살표 | `next_arrow.png` (2프레임, 36×32) | (1168, 644) | 72×32 |
| 건너뛰기 | `btn_skip.png` / `_hover` | (976, 24) | 280×92 |

- 장면 1 평화로운 마을, 2 회색 블록 비, 3 마을 큐브가 깨짐, 4 회색으로 물든 마을, 5 큐비 출발.
- 클릭(또는 스페이스)하면 다음 대사, 장면의 마지막 대사 다음에는 다음 장면 그림으로 바뀝니다. 마지막 대사 다음, 또는 건너뛰기를 누르면 지역 선택으로 갑니다.
- 다음 화살표는 0.4초마다 프레임을 바꿔 위아래로 통통 튀게 합니다.
- 건너뛰기 버튼 아래쪽 16px는 그림자라서 클릭 영역은 위쪽 **0~76px**입니다.
- 장면 아래쪽(대사 상자 자리)에는 중요한 그림이 없으므로 상자로 가려도 됩니다.
- pico2d의 `font.draw(x, y, 글자, 색)`는 x가 글자 왼쪽, y가 글자 세로 가운데입니다. 위 표의 왼쪽 위 좌표 (L, T)는 `font.draw(L, H - T - 18, line, (255, 255, 255))`로 그립니다.

```python
from story_data import OPENING, NAME_PLATES

scene_i, line_i = 0, 0

def next_line():
    """클릭할 때 호출. False를 돌려주면 오프닝 끝."""
    global scene_i, line_i
    line_i += 1
    if line_i >= len(OPENING[scene_i]['lines']):
        scene_i, line_i = scene_i + 1, 0
    return scene_i < len(OPENING)

# 그리기: 장면 그림 → 대사 상자 → (이름표) → 대사 글자 → 다음 화살표 → 건너뛰기
who, text = OPENING[scene_i]['lines'][line_i]
for n, line in enumerate(text.split('\n')):
    font.draw(84, H - (560 + 52 * n) - 18, line, (255, 255, 255))
```

### 지역 선택 (`region/`)

| 요소 | 파일 | 위치 | 크기 |
|---|---|---|---|
| 배경 | `region_select_bg.png` | (0, 0) | 1280×720 |
| 제목 '지역 선택' | `title_region_select.png` | (432, 40) | 416×104 |
| 뒤로 | `buttons/icon_back.png` (기존) | (16, 16) | 72×72 |
| 큐브마을 아이콘 | `icon_village` / `_hover` / `_locked` | (144, 256) | 192×192 |
| 지구 아이콘 | `icon_earth` / `_hover` / `_locked` | (544, 224) | 192×192 |
| 우주 아이콘 | `icon_space` / `_hover` / `_locked` | (944, 256) | 192×192 |
| 이름표 | `name_village.png` (252×84) | (114, 460) | |
| | `name_earth.png` (160×84) | (560, 428) | |
| | `name_space.png` (160×84) | (960, 460) | |

- 잠긴 지역은 `icon_*_locked.png`(회색 + 자물쇠)와 `name_*_locked.png`(흐린 글자)를 쓰고, 클릭해도 반응하지 않게 합니다.
- 마우스를 올리면 `_hover`(밝아지고 1칸 위로, 노란 테두리)로 바꿉니다. 클릭 영역은 아이콘 192×192 전체로 잡으면 됩니다.
- 이름표 아래 진행도(예: ★ 12/30): `windows/star_small_full.png` (28×28)를 (x0, 이름표 위치 + 94)에 그리고, 숫자는 `digits_small.png`로 x0 + 36부터 28px 간격으로 씁니다. x0 = 아이콘 가운데 x − (28 × 글자 수 + 36) / 2.
- `digits_small.png` (364×36): 한 글자 28×36, 순서는 `0123456789+x/` (기존 숫자 폰트와 같은 순서, 크기만 작음).
- 지역 사이의 노란 점선은 배경에 그려져 있어서 아이콘을 위 위치에 놓으면 맞물립니다.
- 잠금 규칙: 앞 지역의 마지막 스테이지를 깨면 다음 지역이 열립니다 (`story_data.is_unlocked`).
